# Personal Site

One-page academic personal website built with Astro and designed for GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run test
npm run build
```

## Content

- Edit profile, work items, and publications in `src/data/site.ts`.
- Put downloadable files in `public/files/`.
- Put publication images in `public/images/publications/`.
